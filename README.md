# Gilly Interiors website

Static site (HTML/CSS/JS) – works on GitHub Pages. Pages: index, services, shop, gallery, about, contact.

- Add products in `./products.js` (name, category, image path, optional note). No prices – customers tap ORDER to add to the cart, then ORDER NOW sends a WhatsApp quote request.
- All images live in the single `img/` folder (hero photos, gallery, `intro.jpg` = loader image).
